# 🎬 ScreenMatch

Projeto desenvolvido durante meus estudos de **Java e Programação Orientada a Objetos (POO)**, acompanhando as aulas da formação da **Alura**.

O projeto tem como objetivo praticar os conceitos fundamentais de POO em Java por meio da criação e manipulação de uma classe que representa um filme.

## 📚 Sobre o projeto

Neste projeto, estou praticando conceitos como:

* Criação e utilização de classes e objetos;
* Atributos e métodos;
* Encapsulamento;
* Modificadores de acesso;
* Getters e Setters;
* Métodos para manipulação de dados;
* Cálculo de média de avaliações;
* Uso de `printf` para formatação de valores.

A aplicação cria um objeto `Filme`, define suas informações, registra algumas avaliações e calcula a média das notas recebidas.

## 🛠️ Tecnologias

* **Java**
* **IntelliJ IDEA**
* **Git/GitHub**
* **Alura**

## 🎯 Objetivo

Este projeto faz parte da minha etapa de estudos em **Java**, após ter estudado principalmente Python.

Estou utilizando os projetos e exercícios da formação da Alura para revisar fundamentos da linguagem e desenvolver uma base sólida em **Programação Orientada a Objetos**, avançando posteriormente para conceitos mais aprofundados do desenvolvimento back-end.
